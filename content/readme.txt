FE's content/ folder.

Custom charts go here, one folder per category:

	content/CustomCharts/<category>/<song>/<song>.json
	content/CustomCharts/<category>/<song>/Inst.ogg(also can be audio.ogg (osu default))
	content/Customcharts/<category>/<song>/Voices.ogg(or vocals/vocal.ogg(camellia2.7.5default))

And FE Vanilla Songs Package should be right here:

	content/VanillaSongs/BFMix
	content/VanillaSongs/Collab
	content/VanillaSongs/Erect
	content/VanillaSongs/PicoMix

The Freeplay "CONTENT" menu lists every category found under content/CustomCharts/.

Note: this is NOT the same as mods/. Charts placed here show up in the CONTENT
browser; mods/ is for overriding engine assets.
