# 2026-10-31 第四次会话：meltdown 红闪消失 + 脚本报错（videoCutscene 遮蔽 / onFirstEventPush 缺派发）

> 用户报：① meltdown 红色闪屏特效没了（怀疑和 FE 的 Flashing Lights 开关有关）；② meltdown 有脚本报错。
> 日志：`export/release/windows/bin/crash/bread.log`（今天 09:45–11:04 多轮实测）。

## 1. 日志取证

```

06:25:45 / 09:52:39 / 10-30 22:36:57 script: ERROR: script:3: Null Function Pointer   ← danger/script.hx:3，同样必炸
```

- `meltdown.hx:6` / `danger/script.hx:3` 都是 `videoCutscene('weekX/...')`（onLoad 里）。
- **sussus-moogus.hx:3 同样写法却 16 次全程无报错**——静态分析只能定位到遮蔽机制，
  两者的分岔没跑通，但修复（共享域优先读）对所有 caller 一视同仁，不依赖解释它。
- 红闪链：legacy 的 `Reactor Beep` 事件（56 次，value1=0.4）由 `scripts/utils.hx` 处理：
  `onFirstEventPush(event)` 里 `new FlxSprite().makeScaledGraphic(1280,720,0xFFb30000)`
  建 `flashSprite`（红色蒙层），`onEvent` 里 `alpha = .3` + tween 回 0。
  **`onFirstEventPush` 是 NMV 专有回调，port 从未派发（grep source 零命中）**→ flashSprite
  永远是 null → onEvent 命中 `if (flashSprite != null)` 守卫 → 静默跳过 = 红闪没了、且无报错。

## 2. 根因

### 2a. 脚本报错：共享函数被宿主 null 字段遮蔽

`InterpEx.resolve` 旧顺序：locals → variables → imports → **parentFields** → sharedFields。
PlayState 有 `public var videoCutscene:VideoSprite = null;`（FE 视频系统字段），
`parentFields = Type.getInstanceFields(PlayState)` 命中 `videoCutscene` → song 脚本解析到
**宿主的 null 字段**而不是 dialogue.hx 共享出来的同名**函数** → 调 null →
hxcpp "Null Function Pointer"。

harness 检不出：NmvBatchState 没有 videoCutscene 字段 → parentFields 不命中 → 共享域兜底成功。
（02:08 报告 onLoad 全绿 = 这个盲区的直接后果。）

### 2b. 红闪：onFirstEventPush 缺派发

port 的事件链只广播 `onEvent`（triggerEvent 末尾）。NMV 的 `onFirstEventPush(EventNote)`
（每事件名首次触发推一次、先于 onEvent，供脚本惰性建对象）没有对应物。

## 3. 修法（4 处）

1. **InterpEx.resolve**：读路径改为 **sharedFields 先于 parentFields**（NMV LOOSE 语义：
   全局脚本的顶层函数/公共变量永远遮蔽宿主同名字段）。写路径（setTo）保持宿主字段优先
   （songStartCallback 等桥接写入依赖它）。已核对共享导出名与 PlayState 字段无意外碰撞
   （comboX/dbText/videoCheckStory/mom/petRGB/... 均非 PlayState 字段）。
2. **PlayState.triggerEvent**：`nmvScripts != null` 且事件名首次触发时，先于原生 switch 与
   `onEvent` 广播 `nmvScripts.call('onFirstEventPush', [{strumTime,event,value1,value2}], true)`；
   `nmvFirstEventFired:Map<String,Bool>` 记录（每歌每事件名一次，NMV 同款）。
   匿名对象与 Note.hx 的 EventNote typedef 字段面一致。
3. **ClientPrefs 平铺静态**：补 `downScroll/middleScroll/lowQuality`（= data.* 别名，
   此前在 hxcpp 上静默读成 null→false，downscroll 玩家的 utils.hx combo 定位整段失效）与
   `photosensitive`（= `!data.flashing`，NMV"减少闪光"开关；utils.hx 红闪按它走
   camHUD 低强度分支，off=正常 camOther 红闪）。
4. **NmvBatchState**：补 `public var videoCutscene:Dynamic = null;` 镜像字段——
   复刻会撞名的宿主字段面，让 harness 从此能检出"共享函数被宿主字段遮蔽"类回归。

## 4. 验证

  与回调失败 26 个的**失败集合逐项 diff 完全一致**（零回归）；
