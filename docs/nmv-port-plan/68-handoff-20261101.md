## 6. 本轮踩过、以后别再踩的坑

1. **`Matrix.translate` 是纯加**（`tx += dx`），`scale` 才右乘 —— 别再把它当"符号空间"推。
2. **"两条时间线的包围盒不同"不等于"必然错位"** —— 要看参考引擎在同一份 json 上走的是
   哪条判定。bf 就是反例：两端都走子符号，288/207 的差是作者正常配置，我按"必然错位"
   去强行统一，被用户一句"bf 本来是正常的"打回。
3. **同一条 JSON 里，`name` 可能是符号名也可能是主符号帧标签** —— 判据
   `getFrameLabel(name) != null`。真正有 bug 的是"两端判定顺序不同"（bf-fall 的 indices
   vs 标签），而不是"两条路径并存"本身。
4. 探针脚本读 json 要用 `utf-8-sig`（`green/parasite/spritemap1.json` 带 BOM）。
5. 用户会明确纠正"对象是谁"（green 寄生虫 vs bf、bf vs bf-fall）—— 先确认
   `songs/<歌>/data/*.json` 的 `player1/player2`，再去看图集。
