## 关键认知（本轮实证，别再踩）

1. **hxcpp 上 hscript 写缺失字段=抛 "Invalid field:xxx"**（不是静默 no-op）；读缺失
   返回 null。所有对宿主对象的字段写入都是潜在炸点。
2. **flxanimate 的 FlxAnimate.draw 是纯 animate 帧绘制**（drawLimb 链），不认
   sprite.frames、无法回落标准渲染——sparrow 路径必须自画（已做）。
3. **NMV 的 refreshZ(stage) 只排 stage 组**（PlayState:3300 override，角色组在 stage
   组内）；脚本 onCreatePost 起 add() 的对象在组外、永不重排、永远画在最前。
   FE 用 nmvStageZBound 边界等价实现。
4. **NMV note.player = lane = queueNote.playField（0..3）**，mustPress=(player==0)；
   FE Note.player=mustPress?1:0——attack.hx 的 orgID=3-note.player 语义未改。
5. **歌曲脚本目录 = formatToSongPath(SONG.song)**（json 显示名带空格，曾致 20+ 首歌
   脚本整批没加载——max 级教训）。
6. NMV PlayState:913 `refreshZ(stage)` 在 super.create() 之后；onCreatePost 在
   refreshZ 之前（NMV:905）。
7. 内容包里 `danger.json` 有 trailing comma（tjson 容忍）。
8. `.exe` 时间戳先于改动时间 = 用户测的是旧构建（本轮 finale/Double Kill 一度
   "修了没用"就是这个）。
